# 天王寺

オンライン会議の同時通訳アプリです（macOS 版）。

## ダウンロード

[最新版のダウンロードページ](https://github.com/lukeliu95/tennoji-releases/releases/latest)から `.dmg` ファイルをダウンロードしてください。

## インストール

1. ダウンロードした `.dmg` ファイルを開きます。
2. 「天王寺」を「アプリケーション」フォルダにドラッグします。
3. 「アプリケーション」フォルダから「天王寺」を起動します。

## 動作環境

- Apple シリコン搭載の Mac

## アップデート

インストール後は、新しいバージョンが公開されると自動的に更新されます。
